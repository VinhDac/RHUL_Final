Black box

Training DL is like adjusting a million buttons to fit the GOAL: epochs, learning rates, layers, activations, regularization methods, L1, L2, ...

Snooping

Definition

Trying too many configurations, methods to make the results better.

What is the goal? What is better?

Is the goal to make the best validation score, or to make the best test set score? But the test score is used only once, so how do we improve the model when the test score is bad? => We train again to make it good, but the test set is not true anymore. So how do we believe it is good?

Do basic methods not work rightly in specific situations?

For example: split train – valid – test set? Does it work in real life, when in forecasting and categorization the data is not truly random to shuffle it? It itself has its correlations, because the formula already made it normalized for all problems. So if we want it to work specifically on one thing, it does not work.

So, how do we believe the model if even the goal is not trustable, and with DL it is even worse, when it itself works like making the valid score the best? => Conclude: We cannot trust the GOAL

Do the hidden assumptions in the method we use in training the model make the goal wrong? => Data is not totally random to be shuffled => Unclear goal ⇔ train model wrong

=> WE trust in the Procedure of making the model with clear assumptions for each situation
